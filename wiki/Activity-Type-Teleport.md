The Teleport allows moving one or more tokens across a scene.


## Configuring Teleport

![Teleport Sheet - Teleport Tab](https://raw.githubusercontent.com/foundryvtt/dnd5e/publish-wiki/wiki/images/activities/teleport-effect.jpg)

After creating the Heal activity the configuration sheet will open. Navigate over to the "Teleport" tab to see the teleportation distance options. By default the activity will use the range defined on the "Targeting" tab, but if different values are requires the *Override* option can be selected, allowing the range to be set using the *Maximum Distance* input. Leaving the input blank allows teleporting any distance.
